Kairos

Kairos는 개발자 본인의 연구와 생활을 위해 만든 개인 일정·활동 기록 프로그램입니다. Mac에서 Google Calendar를 읽고, 별도로 등록한 할 일을 개인 Telegram 봇으로 알리며, 완료 버튼과 선택 메모를 로컬 기록에 저장합니다.

Google Calendar는 계획의 기준으로 사용합니다. Calendar API 권한은 읽기 전용이며, 실제 수행 기록은 일정과 구분합니다. 사용자가 선택한 반복 수업의 시작·종료 알림을 개인 Telegram 대화에 연결하며, 완료와 선택 메모는 같은 수업 회차에 저장합니다.

이 페이지에는 일정, 연구 자료, 인증정보, 실제 활동 기록을 게시하지 않습니다. 웹에서 회원 가입이나 Google 인증을 제공하지 않으며, 프로그램의 인증은 사용자의 Mac에서 Google 공식 승인 절차로 진행합니다.
