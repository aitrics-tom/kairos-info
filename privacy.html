처리하는 정보와 목적

Kairos는 사용자가 승인한 Google Calendar의 일정 제목, 시작·종료 시각, 시간대, 일정·반복 회차 식별자와 취소 상태를 일정 조회 및 알림 연결에 사용합니다. OAuth의 Calendar 읽기 권한은 해당 Google 계정에서 접근 가능한 캘린더를 읽을 수 있는 범위입니다. 현재 코드는 지정한 개인 기본 캘린더를 확인한 뒤 그 캘린더만 조회합니다.

개인 Telegram 봇은 연결한 본인의 사용자·대화 식별자, 알림 메시지 식별자, 완료·취소·미루기 입력과 사용자가 답장한 선택 메모를 활동 기록·중복 방지·통계에 사용합니다. 다른 사용자나 관계없는 메시지 원문은 기록하지 않습니다. 계획 시각은 실제 수행 시간으로 간주하지 않습니다.

보관과 전달

Google 및 Telegram 인증정보는 이 Mac의 로그인 키체인에 저장합니다. 설정과 활동 기록은 Mac의 별도 폴더 및 SQLite 데이터베이스에 저장하며 파일 접근 권한을 제한합니다. 활동 데이터베이스 자체를 별도로 암호화하거나 외부 자동 백업하는 기능은 현재 적용하지 않았습니다. 운영 로그에는 인증정보와 메시지 원문을 남기지 않습니다.

인증·일정 조회에는 Google 서비스를, 개인 알림과 버튼·메모 처리에는 Telegram Bot API를 사용합니다. Telegram으로 등록한 알림·메모 내용은 Telegram 서비스에서 처리됩니다. Calendar 알림 연결은 사용자가 선택한 반복 수업에 한정하며, 해당 일정의 제목·시각과 완료 상태를 연결한 본인의 개인 Telegram 대화에 전달합니다. 다른 일정 내용을 활동 기록으로 저장하거나 Telegram에 전달하지 않습니다.

이 공개 안내 페이지에 개인 일정이나 활동 기록을 전송하지 않습니다. 프로그램은 Google 사용자 데이터를 광고, 판매 또는 일반 AI 모델 학습에 사용하지 않으며, AI 서비스로 자동 전송하지 않습니다. 사용자가 별도 대화에 직접 제공한 자료는 해당 서비스의 정책이 적용됩니다.

권한과 보관 기간

Google Calendar 권한은 읽기 전용입니다. Gmail·Drive 접근과 Calendar 일정 수정 권한을 요청하지 않습니다. 사용자는 Google 계정의 연결 관리에서 Kairos의 접근 권한을 철회할 수 있습니다. 권한 철회는 이미 Mac에 저장된 활동 기록을 자동 삭제하지 않습니다.

인증정보와 활동 기록은 사용자가 연결 해제 또는 삭제를 요청할 때까지 보관합니다. Mac 키체인의 Kairos 항목, 로컬 설정·데이터베이스와 Telegram 대화 기록은 서로 별도이므로 삭제 범위를 구분합니다. 삭제 및 문의는 아래 연락처로 요청하거나 Mac에서 직접 관리할 수 있습니다.

Google 데이터 이용 원칙

Kairos의 Google API 정보 사용 및 다른 앱으로의 전달은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.
